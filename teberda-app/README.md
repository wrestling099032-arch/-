# 📦 Инструкция по деплою на Sweb.ru

## Структура проекта

```
teberda-app/
├── index.html          # Главная страница (Mini App)
├── admin.html          # Админка (управление контентом)
├── index.php           # Точка входа
├── .htaccess           # Конфигурация Apache
├── api/
│   ├── data.php        # API для данных
│   ├── upload.php      # API для загрузки изображений
│   └── init.php        # Инициализация данных
├── data/               # Папка для данных JSON (создаётся автоматически)
│   ├── routes.json     # Данные маршрутов
│   ├── services.json   # Данные услуг
│   ├── categories.json # Категории
│   └── requests.json   # Заявки
└── images/             # Папка для загруженных изображений
```

## Шаг 1: Загрузка файлов на сервер

### Вариант A: Через панель Sweb (File Manager)

1. Войдите в панель управления https://cp.sweb.ru/
2. Перейдите в **Файловый менеджер** или откройте **WWW**
3. Создайте новую папку, например `teberda-app`
4. Загрузите все файлы из этой папки проекта

### Вариант B: Через FTP/SFTP

1. Подключитесь к серверу по SFTP (порт 22)
   - Хост: ваш домен или IP сервера
   - Логин: ваш логин от панели Sweb
   - Пароль: ваш пароль от панели Sweb

2. Перейдите в папку `www` или `public_html`

3. Создайте папку `teberda-app` и загрузите туда файлы

### Вариант C: Через Git

1. Подключитесь по SSH к серверу
2. Перейдите в папку www
3. Клонируйте репозиторий:
   ```bash
   cd ~/www
   git clone https://github.com/wrestling099032-arch/-.git teberda-app
   ```
4. Добавьте PHP файлы (клонирован только HTML)

## Шаг 2: Настройка домена (поддомена)

### В панели Sweb:

1. Перейдите в **Домены** → **Создать поддомен**
2. Например: `teberda-app.ваш-домен.ru`
3. Укажите корневую папку: `/www/teberda-app/`
4. Сохраните

ИЛИ настройте основной домен:
1. Перейдите в **Домены** → выберите ваш домен
2. В разделе **WWW** укажите папку `teberda-app`
3. Сохраните

---

## Шаг 3: Инициализация данных

После загрузки файлов откройте в браузере:

```
http://ваш-домен.ру/api/init.php?init
```

Или подключитесь по SSH и выполните:
```bash
cd ~/www/teberda-app
php api/init.php
```

Это создаст файлы данных в папке `data/`

В панели Telegram Bot (@BotFather):

1. Откройте вашего бота

3. Укажите URL вашего сайта:
   ```

   ```

## Режим работы админки

Админка по умолчанию работает в **демо-режиме** (localStorage в браузере).

**Для переключения на серверное хранение:**
1. В файле `admin.html` найдите секцию `<script>`
2. Раскомментируйте и настройте блок SERVER_MODE:
   ```javascript
   const SERVER_MODE = {
       enabled: true,
       apiUrl: '/api/data.php',
       uploadUrl: '/api/upload.php'
   };
   ```

## Возможные проблемы

### Ошибка 500
- Проверьте что PHP установлен на хостинге
- Включите отображение ошибок в панели Sweb

### Файлы не сохраняются
- Проверьте права на папки `data/` и `images/` (должны быть 755)

### Изображения не загружаются
- Убедитесь что папка `images/` существует и имеет права на запись
