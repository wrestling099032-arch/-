# Онлайн-меню кафе

| Страница | Для кого | Адрес |
|---|---|---|
| `index.html` | гости (открывается по QR-коду) | `https://ИМЯ.github.io/РЕПОЗИТОРИЙ/` |
| `admin.html` | владелец: управление меню | `…/admin.html` |
| `qr.html` | владелец: печать QR-кодов | `…/qr.html` |

- Все данные меню лежат в `menu.json`, фото — в папке `images/`.
- Админка сохраняет изменения прямо в этот репозиторий через GitHub API (одним коммитом), после чего GitHub Pages обновляет сайт за 1–2 минуты.
- Ключ доступа GitHub хранится только в браузере владельца, зашифрованным его паролем (AES-GCM + PBKDF2). В репозитории секретов нет.
- QR-код стола ведёт на `…/?table=N`: гость видит в меню «Стол N».

Подробная инструкция — в файле «ИНСТРУКЦИЯ.md», который лежит рядом с этой папкой.
