👋 First-time setup

You only need to do this once on each device (phone, computer).

  1. Tap create a key on GitHub (opens in a new tab).
  2. Under Expiration, choose No expiration.
  3. Scroll down and press the green Generate token button.
  4. Copy the key (it starts with ghp_) and paste it here.
