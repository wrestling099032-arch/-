🖨 Table QR codes

Set up and print. Each QR code opens the menu and shows the guest their table number.

  • In the print window choose Save as PDF to get a print-ready file for a print shop.
  • Print at 100% scale (“Actual size”), not “Fit to page”.
  • Best printed on A4 sticker paper and laminated, so it survives wiping the tables.
  • Before printing them all, scan one code with a phone and check that the menu opens.
